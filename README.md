# DumpDetective

High-performance .NET memory dump analyzer.

## Active Repository Layout

Authoritative active code lives under:
- `src/`
- `tests/`
- `DumpDetective.slnx`

Legacy top-level generations are intentionally removed from active development.

Contributor quick start:
1. Open `DumpDetective.slnx`.
2. Build and run from `src/` projects.
3. Run tests from `tests/DumpDetective.Tests`.
