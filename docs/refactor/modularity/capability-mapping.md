# Capability mapping

Generated by `tools/CapabilityMappingAudit` — **required-capability columns are
scripted** (do not hand-edit); the **optional (trace) column is a hand-curated table
embedded in the generator itself** (edit `optionalTraceCapabilities` in
`tools/CapabilityMappingAudit/Program.cs`, then re-run). Re-run with:
`dotnet run --project tools/CapabilityMappingAudit`.

Phase 0 item 3 (see [phase-0-foundation.md](phase-0-foundation.md)): for each analyzer, which capabilities from [source-model.md § 3](source-model.md) it actually needs, and which it would optionally benefit from once trace exists. Direct input to Phase 3's `[RequiresCapability]` attributes and the graded-fidelity design.

**Required** capabilities are derived mechanically from real source: for the 11 analyzers already retyped onto `Sdk.Analysis.IAnalyzer`, from the `AnalysisContext` properties they actually read (each capability-scoped 1:1 — see `src/DumpDetective.Sdk/Analysis/AnalysisContext.cs`); for the remaining 25 still on `Core.Abstractions.IAnalyzer` (or `IDeferredAnalyzer`), from the actual `IHeapAnalysisCache` members and raw ClrMD API calls (`heap.EnumerateObjects`, `Runtime.Threads`, `.Fields`, etc.) found in the analyzer's own class body, each mapped to the capability that the corresponding dump-side `*Query.cs` bridge implementation (`src/DumpDetective.Analysis/Sdk/`) actually exposes it through — not guessed. Syntax-only regex matching, same limitations noted in [contract-surface-inventory.md](contract-surface-inventory.md) apply (possible false positives from identifier collisions, false negatives through local/field aliasing).

**Optional (once trace exists)** is design judgment, not derivable from dump-only source — each entry states its rationale so it can be disputed/revised. Several analyzers list no optional capability because the current `CapabilityVocabulary` (see `src/DumpDetective.Sdk/Artifacts/CapabilityVocabulary.cs`) has no matching trace concept (e.g. no `trace.db-events` for the four DB/SQL analyzers) — flagged as vocabulary gaps for Phase 3/6, not silently omitted.
